## Wan 2.2 template status

This first version validates the RunPod image, boot, storage, and publishing
path only. The T2V and I2V files are empty ComfyUI canvases. No Wan models or
Wan-specific custom nodes are registered yet, so this version cannot generate
video.

Set `download_wan22_t2v=true` or `download_wan22_i2v=true` only to copy the
corresponding placeholder canvas into the ComfyUI workflow list.
